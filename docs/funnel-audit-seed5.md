# Launch Studio — Funnel Audit Seed Batch 5
**Operator brand:** Launch Studio (Isaac Donnelson)  
**House lock:** Close = **LAUNCH + product → DM/call**. Link-in-bio / VSL / long-page studied as craft *and* as **FAIL patterns** when used as the default close. Never recommend installing VSL/page-first as our default close.  
**Audience we sell to:** people launching digital / SaaS / online businesses.  
**What we sell:** SaaS launch + standing Grok bots. Instagram-first. No AI slop. No ad-looking content.  
**Method:** Live fetch via WebFetch + curl (Sep 18, 2026 PT). Quote only what was captured. JS-heavy pages noted where fields/copy didn’t hydrate in static HTML.  
**Target path we train toward:** lead form → early buy option → LAUNCH+product → DM/call → later SaaS upsell.

## SYNTHESIS

### Commonalities across the 5
1. **Free personalized asset** as IG → bio hook (Hormozi roadmap, Nexus Atlas roadmap, Taki Triage Call) — “under 30 seconds” / timeboxed value.
2. **Volume proof** (“Requested by X business owners”) and/or **named peer proof**.
3. **Qualification before intimacy**: application (Ryan, Taki Black Belt), revenue/industry FAQ (Hormozi workshop), problem select (Nexus).
4. **Anti-positioning**: not another country club (Ryan); not motivational event (Hormozi); audition not sell (Taki).
5. **Ladder**: free → workshop/book/community → call/mastermind (except Dr Cole, who collapses to VSL→order).
6. **Founder/authority stack** near the fold or mid-page.
7. **Phone/SMS consent** when call is the close (Hormozi, Ryan).

### Highest-leverage page/funnel pins (train pack)
*Support: lead form → early buy option → LAUNCH+product → DM/call → later SaaS upsell*

**Design**
1. Dark/clean or firm-simple hero; one primary CTA; mobile-first; avoid CF “order form below video” chrome.
2. Problem selector or 1–3 micro-steps *before* heavy fields (Nexus Atlas pattern).
3. Proof as one strong named card or honest volume line — not fake logo walls.

**Copy**
4. H1 = **outcome + personalization + speed** (steal structure from Hormozi/Nexus; swap in Launch Studio outcome).
5. Anti-category one-liner (what we’re *not*) to filter tire-kickers.
6. CTA verbs: Get roadmap / Start / Apply / Book call — not “Claim Your Amazing Product.”

**Forms**
7. Light contact (name, email, phone, one qualifier) → SMS/call consent → **route to DM/call**, not checkout.
8. Optional early-buy module *after* lead, never instead of human close.

**Strategy**
9. Page = **qualify + desire**; close = **LAUNCH + product in DM/call**.
10. Offer ladder: free diagnostic → small product/LAUNCH → standing Grok bots SaaS upsell.

**Visuals**
11. Operator-real screenshots / launch artifacts over stock hustle imagery.
12. No leftover template titles in `<title>` / no “Amazing Product” CF defaults.

### Explicit “do not copy” list
| Pattern | Why FAIL for us |
|---------|-----------------|
| **VSL → order form as default close** (Dr Cole / CF) | Violates LAUNCH+product → DM/call house lock |
| **Page-first cash close** without DM/call handoff | Trains buyers to buy from ads, not operator relationship |
| **“Claim Your Amazing Product” / CF template chrome** | Ad-looking; trust & brand mismatch |
| **Fake or empty testimonial carousels** | Captured VSL “Testimonials” shell with no readable quotes |
| **Luxury status gates** ($1M + golf club) as copy-paste | Wrong audience (launchers, not $1M golf mastermind) |
| **FB webinar CPA brag as hero** | Ad-looking; not IG-native no-slop |
| **Health/pain VSL formulas as primary story** | Wrong niche; compliance risk |
| **Making the long sales page the close** | Craft OK; close mechanism FAIL if it replaces DM/call |
| **AI-slop / generic hustle stock** | Brand lock: no AI slop, no ad-looking |
| **Leaving internal names in title** (“JASON \| VSL + Order Form”) | Amateur trust destroyer |
