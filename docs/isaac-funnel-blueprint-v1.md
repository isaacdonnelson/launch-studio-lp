## House locks (non-negotiable)

1. **Close = LAUNCH + product → DM/call** (Launch Sprint apply). Never VSL / link-in-bio / long-page checkout as the default close.
2. **Unique mix:** SaaS launch + standing Grok bots. Instagram-first. No AI slop. No ad-looking content. No fake proof.
3. **One operator brand** — not D&M / TestFiesta / WorkflowFiesta / Krest ads.
4. **Page qualifies; human closes.** Early buy is optional after lead — never instead of the human close.
5. Study competitor VSL/page closes as **craft + FAIL specimens**, not templates to install.

---

## Buyer

People launching digital / SaaS / online businesses. First ~200 should be this buyer.  
**Not:** luxury status masterminds, health/pain VSL buyers, webinar-ad shoppers, wrong-niche transplants.

---

## Funnel path (signed)

```
Instagram (primary traffic)
  → Bio → operational LP
    → Lead (problem micro-step → light contact + SMS/phone consent)
      → Optional early-buy micro-SKU (named, honest price; after lead only)
        → LAUNCH + product → DM / call / Launch Sprint apply
          → Later: onboarding SaaS + standing Grok bots upsell
```

**Closest models we train from:** Hyros (SaaS → setup/demo call) · Iman Monetise/Apply (software + launch + apply) · PRIME apply (install systems via application).  
**Keep from seed:** Nexus problem-first · Hormozi speed H1 · Taki audition · Ryan anti-category.

## Stage definitions

| Stage | Job | Mechanism |
|-------|-----|-----------|
| **Lead** | Capture intent fast | Outcome+speed H1; one diagnostic question; name/email/phone; SMS consent |
| **Early buy** | Self-select serious buyers | Optional named micro-product ($57–$99 band as craft reference, final SKU TBD) — *after* lead |
| **LAUNCH + product** | Deliver install event + product | Launch Sprint / apply language; “install, don’t study” |
| **DM / call** | Close | Human qualify; “3–4 qualified calls” quality bar; no page-cash default |
| **SaaS upsell** | Standing Grok bots + onboarding | Transparent tiers *after* relationship (Skool-style clarity on backend only) |
