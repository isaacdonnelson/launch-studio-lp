## 1) Strategy system

### Stage jobs
| Stage | Job | Mechanism |
|-------|-----|-----------|
| Lead | Capture intent fast | Outcome+speed H1; 1 diagnostic Q; name/email/phone; SMS consent |
| Early buy | Self-select serious | Optional named micro-SKU ($57–$99 craft band; final TBD) — *after* lead |
| LAUNCH + product | Install event + product | Launch Sprint / apply; “install, don’t study” |
| DM / call | Close | Human qualify; “3–4 qualified calls” quality bar |
| SaaS upsell | Standing Grok bots | Transparent tiers *after* relationship (backend only) |

### Positioning
- **For:** people launching digital / SaaS / online businesses (first ~200 = buyer).
- **Not for:** luxury status masterminds, health/pain VSL buyers, webinar-ad shoppers, wrong-niche transplants.
- **Anti-category:** Not another link-in-bio VSL. Not a motivational course dump. Not a Stan store checkout as the close.
- **Anti-fit wall:** One blunt “might not be for you” section (Codie-style) — silver-bullet seekers vs systems installers.
- **KPI language:** Optimize for 3–4 qualified calls, not vanity lead volume.

### Steal ranking (14)
1. Page qualifies; human closes  
2. Outcome + personalization + speed H1  
3. Problem-first micro-step  
4. SaaS → Book Setup/Demo Call rhyme (Hyros)  
5. Multi-step apply + anti-spam consent (PRIME)  
6. Anti-fit / anti-category filter  
7. Audition / apply language  
8. Light form → consent → DM/call  
9. Software + launch engagement frame  
10. Install, don’t study  
11. Honest proof (volume *or* one named card)  
12. Tactical not motivational  
13. Early-buy micro-SKU after lead only  
14. Qualified-call KPI language  
(+15 backend: transparent SaaS tiers for upsell only)

### Never install (FAIL)
- VSL → order form · CF claim chrome · template `<title>` leaks  
- Stan/Eden/Whop/digital-grid as default close  
- Required long case-study VSL before human close  
- Event deposit + sold-out FOMO as primary  
- Income-claim free-training opt-ins  
- Luxury $1M / status gates · FB webinar CPA hero  
- Empty proof / fake logos · “Not accepting calls” posture  
- Wrong-niche transplants · AI-slop / hustle stock / countdown spam  
- Long sales page *as* the close · Celebrity logo walls that read corporate-ad

## 2) Design system

### Visual principles
- Dark/clean or firm-simple operator UI (Nexus cleanliness > ClickFunnels chrome).
- One primary CTA color; mobile-first; generous tap targets.
- Operator-real screenshots / launch artifacts / bot-ops UI — **not** stock hustle imagery.
- Proof as **one strong card** or honest volume line — never empty carousels.
- No CF “order below video” layout as default.
- Clean document `<title>` / OG — no internal template names.

### Layout (section order)
1. **Hero** — H1 + sub + primary CTA (+ optional volume line)  
2. **Problem micro-step** — one question → Start  
3. **What you get / ladder** — free diagnostic → early buy → Launch Sprint → bots  
4. **Anti-fit / for–not-for**  
5. **Proof** — one named card *or* volume  
6. **Form / apply** — light fields + anti-spam + SMS consent  
7. **Optional early-buy module** (after lead success or below fold secondary)  
8. **Setup/call rhyme** — “Book a setup call” energy for LAUNCH (Hyros rhyme)  
9. **Footer trust** — real artifacts, no fake logos

### Components checklist
- [ ] Single primary button style  
- [ ] Problem selector / chips  
- [ ] Named proof card component  
- [ ] Anti-fit callout block  
- [ ] Consent checkbox + plain-language notice  
- [ ] Early-buy card (SKU, price, one outcome line)  
- [ ] Post-submit confirmation → DM/call / Launch Sprint next step

## 3) Copy system

Systems to build, launch, and grow SaaS and online businesses; Grok bots on standing duties.

### Slot frames (final TBD where noted)
| Slot | Frame | Notes |

## 4) Forms & handoffs

### Lead (Step 1 — PRIME rhyme)
1. Problem micro-step (required)  
2. Name, email, phone  
3. One stage qualifier (optional if problem covers it)  
4. SMS/phone consent — clear, honest  
5. Anti-spam line: “No newsletter spam. This is for Launch Sprint / call routing.”

### Post-submit
- Confirm receipt + set expectation for DM/call or Launch Sprint apply next step.  
- Optional early-buy card on thank-you (never blocks human close).

- Multi-step OK; contact-first; deeper questions after.  
- Audition language; qualify for install event.

- After lead only.  
- Does **not** replace DM/call.

- Backend only after relationship.  
- Transparent tiers (Skool Hobby/Pro clarity). Tier names TBD.
