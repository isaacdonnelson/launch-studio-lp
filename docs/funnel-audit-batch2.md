## SYNTHESIS

### Commonalities across Batch 2
1. **Apply / book-call as serious close** for high-ticket (Codie Typeform, Iman Apply, Joe PRIME apply, Brian Mark bookacall, Limitless apply+strategy call).
2. **SaaS product-led** poles: Skool self-serve; Hyros book-setup (sales-assisted SaaS).
3. **Creator digital-product grids** (Dan Eden/Stan, Steve Mellor Stan) = Instagram-native monetization without calls.
4. **Case-study / VSL assist** still common before apply (Iman apply, Brian Mark 20-min).
5. **Anti-fit filters** (Codie “might not be for you”; Joe revenue band; Iman “already winning”).
